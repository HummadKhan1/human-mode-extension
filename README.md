# human-mode-extension
For people who want to use websites without AI features pushed at them

Who: People who want to use websites without AI features pushed at them — search results cluttered with AI Overviews, shopping sites nudging an "AI assistant" instead of filters, support pages hiding a human contact option behind a chatbot.

Bottleneck: Existing solutions (Bye Bye Google AI, EAI, etc.) are hardcoded CSS selector lists — they only work on the specific sites someone manually wrote selectors for, and break the moment a site redesigns.

The agent's job: Look at any website's structure, semantically identify which elements are AI-injected/AI-promoting vs. core human-usable content, and restore a human-first interface — even on sites it's never seen before.
